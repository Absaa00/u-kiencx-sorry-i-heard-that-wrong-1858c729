A [make.fun](https://make.fun) entry for **Sorry, I Heard That Wrong**: a
program that writes the funniest one-line apology a smart speaker gives
after mishearing its owner.

## What it does

`main.py` is deterministic, uses no network, and writes exactly one line
(at most 140 characters) to `/output/entry.txt`: the speaker's apology
after hearing "order more paper towels" as "order more hyper owls".

## Run

```sh
python3 main.py
```
